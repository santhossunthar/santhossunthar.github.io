# ReturnDesk Screenshots

Place ReturnDesk setup screenshots in this folder and reference them from `src/data/labs/returndesk.md`.

Example:

```markdown
![VirtualBox network adapter configured](/images/labs/returndesk/virtualbox-network.png)
```

Recommended names:

- `virtualbox-install.png`
- `vagrant-install.png`
- `returndesk-vagrant-up.png`
- `returndesk-login.png`
