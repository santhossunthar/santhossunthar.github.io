# Blog Images

Place blog post screenshots and diagrams in this folder and reference them from markdown files in `src/data/blog-posts`.

Example:

```markdown
![Linux pipeline example](/images/linux-pipeline.png)
```

For post-specific assets, create a subfolder:

```text
public/images/bash-scripting-basics/
  terminal-output.png
```

Then reference it:

```markdown
![Terminal output from the script](/images/bash-scripting-basics/terminal-output.png)
```
