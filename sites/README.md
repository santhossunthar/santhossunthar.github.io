# Split Sites

This directory contains route-focused Next.js apps copied from the main portfolio project.

- `portfolio`: the home/portfolio experience at `/`
- `blog`: blog experience at `/`, posts at `/[id]`, tags at `/tags`
- `labs`: CTF lab experience at `/`, lab detail pages at `/[id]`, setup at `/setup`

Each app keeps the same project conventions as the root app: `src/app`, `src/components`, `src/data`, `src/lib`, `public`, Tailwind, TypeScript, and Next config.

Run an app from its directory:

```sh
npm run dev
npm run build
```
